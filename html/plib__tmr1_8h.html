◆ TMR1_CallbackRegister()

void TMR1_CallbackRegister ( TMR_CALLBACK callback_fn,
uintptr_t context )

Registers a callback function.

This function allows application to register an event handling function for the PLIB to call back when external interrupt occurs. At any point if application wants to stop the callback, it can call this function with "callback" value as NULL.

Precondition
Timer should be initialized properly
Parameters
[in]callback- Pointer to the event handler function implemented by the user
[in]context- The value of parameter will be passed back to the application unchanged, when the eventHandler function is called. It can be used to identify any application specific value.
Returns
None
