◆ PTG_Deinitialize()

void PTG_Deinitialize ( void )

Deinitializes the PTG peripheral of the device.

This function deinitializes the PTG Peripheral Library (PLIB) of the device, returning the PTG peripheral to its default reset state. After calling this function, the PTG peripheral will no longer be operational, and any subsequent PTG operations will fail until re-initialization using the PTG_Initialize API.

Precondition
The PTG peripheral must have been initialized using the PTG_Initialize API.
Parameters
None
Returns
None
Note
This function should be called when the PTG peripheral is no longer required to release resources and ensure proper reset behavior.

Example:

PTG_Deinitialize();

void PTG_Initialize ( void )

Initializes PTG module.

This function initializes the PTG Peripheral Library (PLIB) of the device with the values configured in the MCC GUI. Once the peripheral is initialized, Step Sequence APIs can be used to start the Step Sequence

Precondition
MCC GUI should be configured with the correct values.
Parameters
none
Returns
none

Example:

void main(void)
{
SYSTEM_Initialize();
PTG_Enable();
PTG_StartStepSequence();
while (1)
{
PTG_SoftwareTriggerSet();
bool wdtBit = PTG_WatchdogTimeoutStatusGet();
if(wdtBit){
PTG_StepSequenceStop();
PTG_Disable();
}
}
}
