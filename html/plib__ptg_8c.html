void PTG_Deinitialize ( void )

Deinitializes the PTG peripheral of the device.

This function deinitializes the PTG Peripheral Library (PLIB) of the device, returning the PTG peripheral to its default reset state. After calling this function, the PTG peripheral will no longer be operational, and any subsequent PTG operations will fail until re-initialization using the PTG_Initialize API.

Precondition
The PTG peripheral must have been initialized using the PTG_Initialize API.
Parameters
None
Returns
None
Note
This function should be called when the PTG peripheral is no longer required to release resources and ensure proper reset behavior.

Example:

void PTG_SoftwareTriggerClear ( void )

Clears the software trigger of the PTG peripheral of the device.

This function clears the software trigger bit PTGSWT of the PTGCON register

Precondition
The PTG peripheral must have been enabled using the PTG_Enable API. The Step Sequence configurations should be carefully made in the MCC GUI
Parameters
None
Returns
